## ภาพรวม

เว็บไซต์แนะนำตัวพื้นฐานที่ใช้ไฟล์ HTML โดยตรง เหมาะสำหรับแสดงจุดเริ่มต้นของการจัดโครงหน้าและการเชื่อมเนื้อหาผ่านเว็บ

## ฟีเจอร์หลัก

- `index.html` สำหรับหน้าแรกและภาพ QR Code
- `about_me.html` สำหรับเนื้อหาแนะนำตัว
- รูปภาพและลิงก์ไปยังโซเชียลในหน้า About me

## โครงสร้างและเทคโนโลยี

ใช้ HTML จัดโครงเนื้อหา รูปภาพ และลิงก์ โดยเก็บหน้าเว็บและไฟล์ภาพไว้ด้วยกัน เป็นเว็บไซต์แบบไฟล์ที่ไม่ต้องอาศัยเฟรมเวิร์กหรือขั้นตอน build
