## ปัญหาที่ต้องแก้

คำสั่ง Terminal, การตั้งค่า Docker และฟังก์ชันที่ใช้ซ้ำกระจายอยู่ในบันทึกทั่วไป ทำให้ค้นหาและนำกลับมาใช้ได้ยาก โดยเฉพาะเนื้อหาที่ผสมภาษาไทยกับศัพท์เทคนิคภาษาอังกฤษ

## ส่วนที่รับผิดชอบ

- พัฒนาการเก็บ Code Snippets และบันทึกด้วย Markdown
- สร้าง Fuzzy และ Full-Text Search พร้อมตัวกรองภาษาและ Tag
- ทำ Command Palette ที่เปิดด้วย `Cmd/Ctrl + K`
- ออกแบบหน้าจอที่รองรับทั้งโหมดสว่างและมืด

## การตัดสินใจทางเทคนิค

### เตรียมดัชนีค้นหาระหว่าง Build

ปรับ Tokenizer ให้รองรับภาษาไทยและศัพท์ภาษาอังกฤษ แล้วสร้าง Index ล่วงหน้า เพื่อค้นหาบนฝั่งผู้ใช้โดยไม่ต้องพึ่งเซิร์ฟเวอร์ค้นหาแยก

### ใช้ Astro สำหรับเนื้อหาที่เป็น Static

สร้างหน้าบทความเป็น Static HTML ส่วนการค้นหาและการคัดลอกเป็นปฏิสัมพันธ์ของเครื่องมือ แยกหน้าที่ของเนื้อหาออกจากส่วนที่ผู้ใช้ต้องโต้ตอบ

### ลดขั้นตอนการนำคำสั่งกลับมาใช้

เปิดค้นหาด้วยคีย์บอร์ด และรองรับการใส่ตัวแปรในคำสั่ง เช่น `docker exec -it <container_name> sh` ก่อนคัดลอก

## ผลลัพธ์ของงาน

ขอบเขตผลงานครอบคลุมการจัดเก็บบันทึกและโค้ด การค้นหาแบบมีตัวกรอง และการคัดลอกคำสั่งที่ใช้ซ้ำ ผ่านหน้าจอที่รองรับการใช้คีย์บอร์ด
